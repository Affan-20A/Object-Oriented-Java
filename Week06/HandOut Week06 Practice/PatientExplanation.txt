We overrided only hashCode() this was the main problem.
Impact on JCF:
    A HashSet handles storage using a 2-step process,
    1. It calls hashCode()
    2. It calls equals() to check if the objects are identical.
    Since we did not override equals(), when HashSet called the equals() method only references
    were compared and false returned, and HashSet considered them as distinct objects.

Also when searching HashSet uses equals() to compare objects which returned false.
